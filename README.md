Implemented Features
Part 1 ‑ Registration & Login
1. Username validation (contains underscore; maximum 5 characters)
2. Password complexity validation (minimum 8 characters, uppercase letter, number, special character)
3. Cell‑phone validation (international + country‑code format)
4. User registration and login authentication

Part 2 ‑ Message Creation
1. Auto‑generate unique message ID
2. Generate message hash value
3. Message‑length validation (maximum 250 characters)
4. Three message choices: Send, Disregard, Store

Part 3 ‑ Stored‑Message Menu
1. Display sender and recipient for all stored messages
2. Retrieve and display the longest stored message
3. Search stored messages by message ID

 How to Run
1. Open the project inside NetBeans IDE
2. Verify all four `.java` files exist in the package `com.mycompany.chatapp`
3. Clean and build the project
4. Run `ChatApp.java`
5. Complete registration → Login → Select menu options
